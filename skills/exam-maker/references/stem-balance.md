# 긍정형·부정형 발문 배분

2026-10-06 사용자 지정: 이 사용자의 시험은 **선택형 문항 수 기준으로 긍정형 약 70%, 부정형 약 30%**로 출제한다. 과목별 출제 기준과 함께 적용하며, 사용자가 해당 시험에 다른 비율을 지정하면 그 값을 우선한다. 목표 평균이나 난이도별 배점 비중과는 별개다.

## 목표 문항 수

- 최종 선택형 문항 수를 `N`이라 할 때 부정형은 `floor(0.30 × N + 0.5)`개, 긍정형은 `N − 부정형 수`개로 정한다. 소수는 가장 가까운 정수로 반올림하고 정확히 0.5이면 올린다.
- 예: 20문항은 긍정14·부정6, 22문항은 긍정15·부정7, 30문항은 긍정21·부정9다. 22문항의 실제 비율은 약68.2%·31.8%이며, 정수 문항 수에서 목표에 가장 가까운 배분이다.
- 서술형·단답형·실기형과 공통 안내는 분모에서 제외한다. 배점이나 선택지 개수로 비율을 계산하지 않는다. 선택형이 없으면 적용 대상 없음으로 기록한다.
- 후보에는 각각 긍정형/부정형을 표시하고, 추천 조합과 최종 선택본이 위 배분을 충족하도록 충분한 교체 후보를 준비한다. 후보 전체의 비율이 맞는다는 이유로 최종 선택본의 검사를 생략하지 않는다.

## 실제로 요구하는 판단으로 분류

- **긍정형:** 옳거나 적절한 설명·방법·이유·값 등을 고르게 하는 문항.
- **부정형:** 옳지 않거나 적절하지 않은 설명, 조건에 해당하지 않는 것, 알 수 없는 것, 나머지와 성격이 다른 것 등을 고르게 하는 문항.
- 부정 표현이 들어 있다는 이유만으로 부정형으로 세지 않는다. `자료를 근거로 사용하기 어려운 까닭으로 가장 적절한 것은?`은 적절한 이유를 고르므로 긍정형이다. `다른 관점에서 설명한 것으로 옳은 것은?`도 긍정형이다.
- 합답형도 선택지가 요구하는 최종 판단으로 분류한다. 판단 방향이 불명확하거나 이중 부정인 발문은 비율에 억지로 포함하지 말고 명료하게 고친다.

## 작성과 검토

청사진 단계에서 긍정형·부정형 목표 수를 배정하고, 단원·지문 묶음과 평가 요소에 걸쳐 배치한다. 단순히 `적절한`을 `적절하지 않은`으로 바꾸지 않는다. 부정형으로 작성하거나 전환할 때는 정답이 되는 오류·부적합 조건을 설계하고 모든 선택지, 정답, 해설, 배점·난이도와 중복 여부를 다시 검토한다. 문항 내용에 적합한 발문을 쓰면서 동일한 표현의 과도한 반복도 확인한다.

국어 부정형은 [국어 지침 5.5](middle-school-korean.md#55-발문-강조와-참조-기호-띄어쓰기-사용자-지정-필수-규칙)에 따라 부정의 뜻을 결정하는 말에만 굵게와 밑줄을 적용한다. 다른 과목에서는 해당 학교의 강조 규칙과 언어 관례를 따른다.

추천 조합, 문항 교체·추가·삭제 후, 최종 편집 후에 다시 집계한다. 검토표에 `선택형 총수 / 긍정형 수·비율 / 부정형 수·비율 / 목표 수 충족 여부`를 적고, 목표에서 벗어나면 문항을 보완한 뒤 재검토한다. 사용자 지정이나 평가 형식상 예외가 있으면 사유와 적용한 배분을 명시한다. 기존 국어 편집 샘플은 이 비율을 적용해 재출제한 문서가 아니므로 비율 충족의 검증 근거로 사용하지 않는다.
