# 본인 기출의 지문 문단 테두리

2026-10-05 사용자가 공통 지문을 기존 출제물처럼 **한글 문단 모양의 테두리**로 작성하도록 지정했다. 지문이 들어가는 표나 글상자를 새로 만드는 방식으로 대신하지 않는다.

## 직접 확인한 설정

`2023-3-2-중간-국어-문제지(완성).hwp`의 한글 변환본은 지문·시·출처34문단에 연결 테두리를 적용했다. 해당 파일의 paraPr39/65/66/69→borderFill27이다. 네 변은 검정 실선0.1mm, 채움 없음, `connect=1`, `ignoreMargin=0`, 오프셋 좌85/우0/상85/하85 HWPUNIT(85≈0.3mm)이다.

`25-3-2-기말-국어-시험지(김형훈 추가 및 수정).hwp`에서도 토론·시·설명 지문·출처41문단에 검정 실선0.1mm와 `connect=1`을 확인했다. 이 파일은 네 방향 오프셋0이다. ID는 해당 파일의 내부 참조이며 다른 문서에 그대로 넣지 않는다. borderFill에 diagonal 속성이 있어도 slash/backSlash가 NONE이면 대각선은 비활성이다.

## 적용 범위와 작성

- **2026-10-07 사용자 수정 기준:** 지문 테두리가 단의 왼쪽에 붙지 않게 좌우를 같은 폭으로 안쪽에 배치한다. 위의 좌85/우0은 과거 문서 관찰값이며 새 문서에 그대로 강제하지 않는다. 문단의 왼쪽·오른쪽 여백을 같게 하고, 테두리의 좌우 간격도 같은 양수로 둔다. `ignoreMargin=1`로 문단 여백을 테두리 위치에 반영하고 문단 여백을 테두리 간격보다 크게 하여 양쪽 단 경계에서 떨어뜨린다. 한글2024 실측에서0은 단 경계 기준 테두리를 그렸고,1은 문단 여백을 반영했다. 이름만 보고 반대로 해석하지 않는다. 적용 예는 HwpUnitChar CASE의 문단 좌우425, DEFAULT의 좌우850, 테두리 좌우142 HWPUNIT이다. 한글 재저장 시 DEFAULT를 CASE의 두 배로 직렬화하므로 두 분기의 원시 숫자가 아니라 환산한 간격을 비교한다. 테두리 속성의 간격은 두 배로 바꾸지 않는다. 출처 문단까지 같은 폭을 유지하되 출처의 오른쪽 정렬은 유지한다.

- 공통 지시문은 밖에 두고 첫 지문 문단부터 마지막 출처까지 감싼다. `(가)(나)`별로 불필요한 가로선을 넣지 않고 같은 지문의 문단 테두리를 연결한다. 발문·선지는 지문 상자 밖에 둔다. 보기/조건 테두리와 지문 테두리를 구별한다.
- 본문 직계 문단의 `paraPr > border`와 그에 연결된 `borderFill`을 사용한다. 표·도형·글자 테두리를 사용하지 않는다. 원본 스타일을 덮어쓰지 않고 새 정의를 추가한다.
- 한양신명조 지문10pt·발문11pt와 원래의 강조·밑줄을 유지한다. 기출의 화자 이름용 내어쓰기나 시의 줄간격을 산문에 일괄 복제하지 않는다.
- 긴 지문은 `keepLines=0` 등 자연스러운 단/쪽 넘김을 허용한다. 긴 지문 전체를 분할 불가 블록으로 묶지 않는다. 수동 분할이 필요하면 문장 경계에서 나누고 원문의 모든 글자·강조가 이어지는지 대조한다. 다음 단의 이어진 문장에 `(가)` 등을 중복해서 붙이지 않는다.
- 테두리 추가 뒤 실제 한글 줄바꿈을 다시 계산한다. 한 줄이 다음 단으로 흘러간 뒤 기존 강제 단 나눔까지 실행되면 빈 단이나 무제목 쪽이 생길 수 있으므로 전체 쪽수를 다시 확인한다.
- 한글에서 지문 커서를 놓고 **문단 모양 → 테두리/배경**에 해당 설정이 나타나는지 확인한다. 출력에서는 지문 양옆 선의 연속, 단/쪽 경계, 출처 아래 닫힘, 글자와 선의 간섭을 검사한다.

검증기에는 `--passage-manifest`로 지문·출처 역할이 기록된 작성 명세를 전달해 문단 테두리 구조를 검사한다. 저장 전후 비교와 모든 쪽의 시각 검사도 함께 수행한다. 실제 하단 배치는 [하단 배치 규칙](continuation-and-bottom-space.md)을 따른다.

좌우 대칭은 `scripts/check_symmetric_margins.py <exam.hwpx> --manifest <authoring-manifest.json>`으로 별도 검사한다. 이 검사는 역할이 명시된 본문 문단만 검사하며 학교 원안지의 외곽선·머리말 표를 변경하지 않는다. 여백 증가로 줄 수가 늘 수 있으므로 수정 뒤 전체 쪽수와 후반부의 강제 단 나눔을 다시 검수한다.
