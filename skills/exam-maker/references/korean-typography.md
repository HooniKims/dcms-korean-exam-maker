# 국어 시험지 글자 크기 — 사용자 지정과 기존 파일 확인

## 적용 결정

2026-10-04 사용자가 최종적으로 **발문 11포인트, 긴 지문 10포인트**를 지정했다. 이 사용자의 국어 시험지에서 발문과 긴 제시문을 구분해 적용한다. 선택지·짧은 보기·공통 지시문·머리말·쪽번호·저작권 문구 등 별도 지정이 없는 요소는 기존 원안지의 역할별 서식을 따른다. 문서 전체를 10pt 또는 11pt로 일괄 변경하지 않는다.

연수자료의 공통 체크리스트에는 신명조 11pt가 적혀 있다. **원문 일반 기준 11pt / 현재 국어 적용: 발문 11pt·긴 지문 10pt**로 구분한다. 다른 학교에도 이 조합이 의무라고 일반화하지 않는다. 이후 사용자 지정이 있으면 그 값을 반영한다.

확인한 기존 HWP의 주된 명조체 이름은 **한양신명조**다. 이 프로젝트의 국어 원안지는 해당 글꼴을 우선하고, 연수자료의 ‘신명조’ 표현과 원안지의 실제 글꼴명을 구분한다. 설치되지 않은 글꼴은 렌더링 대체 여부를 보고한다. 기본 템플릿의 9pt나 HWPX 도구의 기본 Pretendard가 선택된 서식을 덮어쓰지 않도록 직접 런·스타일을 확인한다.

## 확인 방법과 결과

원본 HWP 3개를 HWPX 스킬의 rhwp 변환 함수로 작업용 HWPX에 변환하고 `--verify`를 통과했다. header.xml의 charPr height(1/100pt), 한글 fontRef, 실제 section의 텍스트 런을 연결하여 읽었다. 원본 파일은 수정하지 않았다. 사용되지 않은 스타일 수를 세는 대신 실제 텍스트 문자 수를 집계했다. 기존 양식 HWPX도 같은 방식으로 읽었다.

| 확인 자료 | 실제 사용 서식 | 해석 |
| --- | --- | --- |
| 2023-3-2-기말-국어-문제지.hwp | 한양신명조 10pt 7,943자 / 11pt 4,601자; 돋움 10pt 2,265자 | 긴 지문에 10pt를 많이 사용하며 다른 크기도 혼용 |
| 23-3-1-중간-국어-시험지.hwp | 한양신명조 11pt 4,992자 / 10pt 762자; 돋움 10pt 1,594자 | 10pt와 11pt 혼용 |

| 원안지양식.hwpx | 한양신명조 11pt 684자; 12pt·15pt와 저작권 돋움 9pt도 존재 | 발문 11pt를 유지하고 새로 넣는 긴 지문은 10pt 적용 |

문자 수는 공백 양끝을 제거한 텍스트 런의 집계이며 머리말 등도 포함한다. 표는 주요 서식만 요약했다. 원본의 모든 글자가 10pt였다는 뜻이 아니다. 화면·인쇄 조판의 완전 일치는 이번 서식 읽기 검사의 범위가 아니다.

## 작성·검수

1. 발문에는 11pt, 긴 지문에는 10pt를 명시하고 한양신명조 사용 여부를 확인한다. 문단의 역할로 분류하며 문자 수만으로 자동 판단하지 않는다.
2. DOCX는 직접 지정 크기와 상속 스타일이 충돌하지 않게 한다. HWPX는 실제 charPrIDRef와 발문 height=1100, 긴 지문 height=1000을 연결해 확인한다. DOCX는 발문 w:sz=22, 긴 지문 w:sz=20(반 포인트 단위)을 확인한다.
3. 선택지·짧은 보기·공통 지시문과 제목·머리말 등은 원안지의 역할별 서식을 유지하고, 크기가 다른 이유를 구분해 기록한다.
4. 렌더링 후 밑줄·원문자·선택지 정렬·쪽 넘김·가독성을 확인한다. 10pt보다 더 줄이는 것은 별도 사용자 결정 없이 하지 않는다.
5. `reflow_two_column_docx.py`는 본문 크기를 하나로 덮어쓰므로 최종 혼합 크기 문서에 그대로 사용하지 않는다. 구조 정리를 위해 사용했다면 발문·긴 지문 역할에 따라 11pt/10pt를 다시 적용하고 검사한다.
6. 글자 크기 외의 연수자료 편집 예시 19개 항목은 그대로 적용한다.
