# 학교 출제연수 지침 — 2026학년도 2학기

이 문서는 `2026_2학기_출제연수자료.pdf`의 **PDF 3~4페이지(인쇄 쪽수 5~8), 붙임 2 「평가 문항 편집 예시」 1~19항**을 원본 이미지와 직접 대조해 정리한 작업용 기준이다. **PDF 2페이지 오른쪽(인쇄 4쪽), 붙임 1 「원안지 출제 및 제출 전 체크리스트」**도 대조했다. 문항 작성·편집 시 아래 기준을 확인한다.

- 원본 PDF는 6페이지이며, 각 PDF 페이지 안에 인쇄물 2쪽이 함께 스캔되어 있다.
- 자동 OCR 본문은 원문 대조 없이 작성 규칙으로 확정하지 않는다. 기호·날짜·고유명사의 오인식을 원본 이미지와 대조한다. 아래 19항과 제출 체크리스트는 원본 대조를 완료했다.
- 이 문서는 규칙의 뜻을 정리한 검토본이며 원문 전체의 교정본은 아니다. 아래 예시는 형식 설명용이며 실제 출제 문항이 아니다.

## 적용 범위와 우선순위

- 이 스킬을 업데이트한 `시험문제_출제` 프로젝트의 2026학년도 2학기 출제 작업에는 이 프로필을 적용한다. 사용자 제공 `2026_2학기_출제연수자료.pdf`, 해당 자료의 원본 대조 안내, 또는 이 연수 지침 적용 요청으로 범위를 식별한다. 실제 파일명은 Unicode 정규화(NFC) 후 비교한다.
- 다른 학교·다른 연수자료에는 이 프로필의 글꼴·인쇄·제출 순서를 보편 규정으로 적용하지 않는다. 해당 학교의 최신 지침을 먼저 확인한다. 학년·과목·시험 범위·시험일·배점은 이 프로필에서 추정하지 않는다.
- 현재 사용자가 확정한 조건 → 해당 시험에 적용되는 학교의 명시적 출제·편집 지침 → 학교 원안지의 구조 → 기존 편집 관례 → 스킬 기본값 순서로 적용한다. 이미 주어진 사용자 결정은 다시 승인받지 않는다.
- 원문 공통 기준은 **신명조 11포인트**다. 다만 사용자는 2026-10-04 **국어 발문은 11포인트, 긴 지문은 10포인트**로 지정했다. 국어는 이 사용자 지정값을 우선하며 기존 원안지의 한양신명조를 사용한다. [국어 글자 크기 실측과 적용값](korean-typography.md)을 함께 읽는다. 국어 외에는 별도 지시가 없으면 원문 공통 기준을 적용한다. 스킬의 일반 기본값 9포인트가 이를 덮어쓰지 않는다. 원안지의 머리말·용지·단·테두리 등 구조는 유지하면서 본문 서식을 맞춘다. 분량을 맞추려고 지정 글자 크기를 줄이지 않는다.
- 신명조가 설치되지 않아 다른 글꼴로 렌더링되면 그 사실과 대체 상태를 알린다. 실제 표시를 확인하지 않고 글꼴 준수가 검증됐다고 하지 않는다.
- 연수자료에서 정하지 않은 줄간격은 제공 원안지나 이미 확정한 값을 따른다. 스킬의 160%를 학교 연수자료의 의무 수치로 설명하지 않는다.
- 별도 지침과 값이 충돌할 때에는 충돌하는 항목만 밝히고 최신 자료와 사용자 결정을 반영한다. 모든 작업을 일률적으로 다시 승인받는 관문으로 만들지 않는다.

원안지의 상단 정보는 고정 문구가 아니다. 학년도·학기·고사명·시행일·요일·교시·학년·과목·문항 수·쪽번호를 실제 시험에 맞게 바꾸고, 표 치수·병합·위치와 본문2단·꼬리말은 유지한다. [원안지 보존 기준](deungchon-original-form.md)을 따른다.

사용자의 최신 지정에 따라 실제 공통 지시문은 **`다음을 읽고 물음에 답하시오.`**를 문항 범위와 함께 굵은 한 줄로 쓴다. 아래 원문 6항의 `다음 글을`은 출처 관찰 기록이며, 현재 출력 문구를 덮어쓰지 않는다.

## 3. 합답형의 실제 배열 기준

보기 항목이 `ㄱ·ㄴ·ㄷ·ㄹ`일 때, 각 선택지 안의 기호도 순서대로 쓴다.

**선지별 구성 항목 수가 같을 때**

> 이에 대한 설명으로 옳은 것만을 <보기>에서 고른 것은?
>
> ① ㄱ, ㄴ　② ㄱ, ㄷ　③ ㄴ, ㄷ　④ ㄴ, ㄹ　⑤ ㄷ, ㄹ

**선지별 구성 항목 수가 다를 때**

> 이에 대한 설명으로 옳은 것만을 <보기>에서 **있는 대로** 고른 것은?
>
> ① ㄱ, ㄴ　② ㄱ, ㄷ　③ ㄴ, ㄹ　④ ㄱ, ㄴ, ㄷ　⑤ ㄴ, ㄷ, ㄹ

위 배열은 원본의 형식 예시를 정리한 것이다. 실제 문항에서는 정답과 오답의 타당성을 별도로 검토한다. 붙임 1은 `모두 고르시오(2개)`처럼 답을 여러 개 직접 선택하는 다답형을 지양하고, 항목 조합 하나를 고르는 합답형을 지향하도록 안내한다.

## 4. 제출 체크리스트에서 함께 적용할 사항

원본 대조 위치: PDF 2 오른쪽, 인쇄 4쪽.

- [ ] 원문 공통 기준은 **신명조 11포인트**이나, 현재 국어 작성에는 **발문 11포인트·긴 지문 10포인트·원안지 한양신명조**를 적용한다. 제목·머리말 등 본문 외 요소는 원안지의 역할별 서식을 유지한다.
- [ ] 문항 간 간격을 균등하게 하고 보기 번호 배열을 고르게 맞춘다.
- [ ] 선택지 번호는 문항 번호보다 **2스페이스 안쪽**으로 배치한다. 글자 수가 많으면 1스페이스도 가능하나 모든 문항에서 통일한다. 실제 문서에서는 일관된 들여쓰기로 구현한다.
- [ ] 그림·사진을 작거나 흐리지 않게 배치한다.
- [ ] 부정형의 `않은/다른`에 **밑줄과 굵게를 모두** 적용한다.
- [ ] 모든 문항의 배점을 표시하고 원안지·문항정보표·서술형 답안지의 배점이 일치하는지 확인한다.
- [ ] 난이도에 따라 배점을 2~3단계 정도로 다양화하고, 쉬운 문제의 배점을 높이고 어려운 문제의 배점을 낮추는 역배점을 지양한다.
- [ ] 선택형·서술형 배점은 교과 평가계획과 일치시킨다.
- [ ] 서술형 유사답·부분답 인정 기준 및 부분점수를 명확히 쓴다.
- [ ] 고사명, 시행일, 교시, 학년·과목, 학생 기재 사항을 확인한다. 1인 1개 학년 담당이어도 공동출제로 작성하고 서명·도장 기재를 확인한다.
- [ ] 채점기준표에는 학년·과목을 명시한다. 나이스 업로드는 학교 제출 절차이며, 실제 업로드는 사용자가 요청한 범위에서만 수행한다.
- [ ] `다음 쪽에 계속/다음 장에 계속/끝`, 저작권 문구, 학교마크를 확인한다.
- [ ] 문항정보표는 양면, 원안지는 단면 인쇄한다.
- [ ] **문항정보표 → 채점기준표 → 시험지(원안지) → 서술형 답안지** 순서로 제출한다.

## 5. 출제 내용 및 검토의 기준

다음은 PDF 1, PDF 5의 자동 추출 본문을 바탕으로 정리한 내용 요약이다. 19개 편집 항목과 달리 세부 문구 전체를 확대 대조한 전사본은 아니다.

- 가르친 교육과정 범위·수준과 성취기준 안에서 출제하고 선행학습이나 과도한 난도를 유발하지 않는다.
- 시중 참고서·온라인 문제 등의 전재(일부 변경 포함), 과년도 문제 재출제를 피한다.
- 공동 출제·공동 검토를 하며 정답 논란, 정답 부재, 차별·편견을 유발할 표현을 확인한다.
- 정답 단서, 중복되는 선지, 지나치게 길이가 다른 선지, 정답 위치 편중, 매력 없는 오답을 검토한다.
- 서술형에는 평가 요소별 배점, 유사정답, 부분점수를 포함한다.
- 시험 시간 안에 풀 수 있는 분량인지 확인한다.
- 축소·삭제된 구 교육과정 내용이 섞이지 않게 하고, 학급별 수업 범위와 시험 안내가 일치하는지 확인한다.
- 수행평가 계획까지 요청받은 경우에는 수업시간 중 실시, 과제형·암기식 지양, 사전 공지한 평가·채점 기준과 실제 평가의 일치, 특정 시기 집중 여부를 함께 확인한다.
- PDF 5~6의 규정에는 시험 파일 암호 설정, 학교가 정한 저장·보관 방식, 네트워크 전송 금지, 인쇄·보관·폐기 관리가 포함된다. 실제 미공개 출제물 처리에는 적용되는 학교 원문을 확인하며, 연수자료 파싱에 대한 API 사용 승인을 미공개 시험지의 외부 전송 승인으로 확대하지 않는다.
- 이 스킬은 문항·검토 자료를 작성한다. 학교의 공동 검토·결재·인쇄·배부·보관 절차를 대신 완료했다고 보고하지 않는다.
