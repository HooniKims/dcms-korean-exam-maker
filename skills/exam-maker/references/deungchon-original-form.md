# 등촌중학교 원안지 — 내용 갱신과 레이아웃 보존

2026-10-04 지정 원안지의 ZIP/XML, 미리보기와 **한컴 한글2024에서 연4쪽 전체 PDF**를 확인했다. [기출·본인 출제물 관찰 기록](exam-form-source-observations.md)을 함께 읽는다. 다른 학교에 이 치수·관례를 자동 적용하지 않는다.

## 작성 범위

사용자 최종 지시: **“상단 정보도 시험 때마다 바꿔야지! 바꿀 수 있게 해. 내용은 바꿀 수 있고, 전체 레이아웃이 흐트러지지 않아야해.”**

| 영역 | 변경할 내용 | 유지할 구조 |
|---|---|---|
| 첫 쪽 상단 | 시행일·요일·교시, 학년도·학기·고사명, 학년·과목, 선택형·서술형 문항 수, No.:1/N | 기존 표 크기·행열·병합·셀 너비·테두리·위치·정렬·글꼴 |
| 이어지는 쪽 상단 | 학년도·학기·고사명·학년·과목, No.:n/N | 전폭 표의 크기·위치·셀/문단 서식 |
| 본문 두 단 | 공통 지시문·지문·발문·선택지·보기·조건·그림·표·배점, 서술형 안내·끝/넘김 문구·마지막 배점 합계 | 본문 영역·단 폭·단 간격·중앙선·문항 가독성 |
| 꼬리말·쪽 외곽 | 기본 변경 대상 없음 | 저작권·학교명·교표·위치, 바깥 테두리·용지·여백 |

‘본문만 작성’은 문제를 넣을 위치에 대한 제한이며 상단 값 동결이 아니다. 정답·해설·채점표·검토 메모는 요청 없이는 학생용 원안지에 넣지 않는다. 과거 정답 형광 표시도 가져오지 않는다.

본문 시작에는 상단 정보와 중복되는 문항 수·유형별 배점·총점 안내를 넣지 않는다. 예: `※ 선택형 22문항(78점), 서술형 4문항(22점) / 총점 100점.`은 생략한다(2026-10-05 사용자 지정). 첫 공통 지시문 또는1번 문항으로 바로 시작하며, 삭제한 안내 대신 빈 문단을 남기지 않는다. 상단 표의 문항 수는 유지하고 마지막 끝 문구는 이 지시만으로 삭제하지 않는다. 첫 단의 지문 흐름을 재조정한 뒤 하단 배치를 다시 확인한다.

상단 정보는 **본문에 매달린 떠 있는 표**다. 실제 header는 비어 있고 footer에 저작권·학교명·교표가 있다. 상단 표를 반복 머리말로 옮기지 않는다.

문항 수 셀에는 기존 문단을 복제해 같은 서식의 둘째 줄을 추가할 수 있다. 기출에서도 선택형·서술형 두 줄을 쓴다. 셀 높이·폭을 늘려 다른 영역을 밀어내지 않는다. 이어지는 쪽은 (0,0)의 한 줄에 정보와 쪽번호가 들어 있다. 앞쪽 공백 run과 아래 여백 행을 보존한다.

**p0 전체 삭제 금지:** 구역·단 설정, header/footer, 첫 쪽 표와 본문 안내가 함께 있다. 본문 글자 run만 찾아 고친다. 확정되지 않은 시험정보는 이전 연도에서 추정하지 않는다. 뒤쪽 표의 `2025학년도 1학기 (중간)고사`도 매번 갱신할 견본값이다.

## 본문과 쪽 배치

1. 새 출력 경로에 원본을 복사하고 해시를 기록한다. 본문 예시·옛 날짜·배점을 견본으로 구분한다.
2. 공통 지시문→제시 자료→발문→보기/조건→선택지/서술형 요구 순으로 문항 블록을 만든다. 공통 지문은 [문단 모양의 연결 테두리](passage-paragraph-borders.md)로 감싼다. 지문·출처만 적용하고 공통 지시문·발문은 밖에 둔다. 공통 지문과 개별 보기를 구별한다. 새 시험에 필요 없는 예시를 제거한다.
3. 한양신명조 발문11pt·긴 지문10pt를 적용한다. 나머지는 역할별 기존 서식과 [학교 지침](school-training-2026.md)을 따른다. 원본 charPr17=일반11pt, charPr1=일반10pt이나 매번 확인한다. 긍정어 무강조, 부정어만 굵게+밑줄, 원문자 뒤 한 칸 규칙을 유지한다.
4. 기존 charPr/paraPr/fontface를 전역 변경하지 않는다. 새 정의는 목록 끝에 추가하고 itemCnt를 갱신한다. 같은 ID라도 중간 삽입은 하지 않는다.
5. 상자·표·그림은 들여쓰기·바깥 여백을 포함해 한 단 안에 둔다. 짧은 보기·조건은 발문과 함께, 긴 지문은 필요 시 단·쪽 경계에서 이어지게 한다. 한 단보다 긴 지문을 분할 불가능한 개체로 묶지 않는다.
6. 왼쪽 단→오른쪽 단→다음 쪽 흐름. 발문만 앞쪽에 남거나 선지1개·배점만 다음 단에 남지 않게 한다. 시의 행·연과 대화의 화자 등 의미 구조를 보존한다. 산문 `(가)(나)(다)` 사이에는 임의 빈 문단을 넣지 않는다.
7. 원본 빈 문단을 일괄 삭제하지 않는다. 블록을 채운 뒤 한컴 조판에 맞춰 단·쪽 나눔과 표 앵커를 조정한다. 상단 표의 상대 위치 속성은 유지하되 앵커가 올바른 쪽에 오게 한다.
8. **원본4쪽은 고정값이 아니다.** 분량에 따라 이어지는 쪽 표를 동일 구조로 복제/삭제하고 새 객체 ID를 부여한다. 첫 쪽 표1개와 각 이어지는 쪽 표1개를 유지한다. 실제 시험지N쪽이면 모든 No.:n/N을 갱신하고 합본의 별도 답안지는 N에서 제외한다. 쪽수를 맞추려고 지정 글자 크기를 줄이지 않는다.
9. 끝/넘김 문구를 실제 인쇄 순서·학교 관례와 맞추고 마지막 쪽에 넘김 문구를 남기지 않는다. 배점 합계와 문항 수는 현재 문항에서 재계산한다. 예시20+2문항·100점을 고정하지 않는다.

발문 번호 뒤 실제 탭·내어쓰기 정렬, 원본 `<보기>`/`<조건>` 개체, 마지막 `<끝>` 및 배점별 문항 수·소계·총점 문단은 [네이티브 구성 요소](native-exam-components.md)를 따른다. 마지막 집계를 한 줄 합계로 대체하지 않는다.

상단 글자가 넘치면 잘못된 공백·중복 표기를 먼저 정리한다. 과목명 자르기, 글자·표 임의 축소로 통과시키지 않는다. 실제 고사명이 기존 틀에 안 들어가면 필요한 변경을 구체적으로 제시한다.

## XML와 한컴 확인

- Windows에서는 [Computer Use로 한글 직접 편집](windows-hancom-computer-use.md)이 기본이다. 기존 Mac에서의 보류를 재사용하지 않고 바로 실행한다. 실제 상단/본문 편집·저장·재열기와 전체 시험 분량의 검증을 수행한다.

- 텍스트는 대상 셀/본문의 `<hp:t>` 안에서만 치환한다. 연도·숫자를 XML 전체에서 바꾸면 크기·좌표·ID까지 훼손된다. 인라인 밑줄·기호·탭·수식·그림 연결과 ZIP mimetype 무압축·namespace를 보존한다.
- HWPX 스킬의 관련 편집·후처리·검증 절차를 따른다. 기존 사용자 허가를 다시 묻는 일반 관문을 추가하지 않는다.
- 한컴 COM에는 절대 경로를 준다. 사본을 열고 PageCount로 조판을 끝낸 뒤 PDF를 내보낸다. 원본에는 Save하지 않고 자동화가 연 창만 정리한다.
- 한컴 SaveAs(HWPX)는 실측에서 paraPr39개와 image1.jpg 바이트를 바꿨다. **원본 기준 파일은 보존하되, 사용자가 한글에서 직접 편집·저장한 HWPX를 최종본으로 사용할 수 있다.** 준비본에는 엄격한 XML 보존 검사를, 한글 저장본에는 참조 ID 정규화와 이미지 재인코딩을 구분한 의미/좌표/시각 검사를 적용한다. 한글 저장본으로 원본 기준을 교체하거나 모든 차이를 무조건 허용하지 않는다. 줄 배치만 이식하더라도 상단 높이·꼬리말까지 덮어쓰지 않았는지 비교한다.

## 검사

스킬 폴더 기준 예시. `--pages`는 실제 원안지 쪽수이며 생략하면 원본처럼4개 표를 요구한다. `--pdf`는 PyMuPDF가 필요하고, 별도 답안지가 없는 한컴 PDF를 준다.

```powershell
python scripts/check_school_form.py "결과.hwpx" --pages 6 --expected-header "확정시험정보.json" --pdf "결과_한컴.pdf"
```

확정시험정보 JSON에는 확인된 값만 담는다. 아래는 형식 설명용 가상값이다.

```json
{"year":2026,"term":2,"exam":"중간","grade":1,"subject":"국어","date":"2026-10-15","weekday":"목","period":1,"choice_count":22,"constructed_count":4}
```

- 자동 검사: secPr/colPr/header/footer, 기존 스타일 정의·순서·itemCnt, 글꼴, 교표 바이트·manifest 연결, 상단 치수·병합·위치·셀/문단/글자 서식, 표 개수·중복ID·순차 쪽번호. 상단 값 변경과 같은 서식의 문항 수 둘째 줄은 허용한다.
- expected-header: 지정한 시험정보가 첫 쪽과 이어지는 쪽에 맞는지 검사. 본문 문항 수·배점 합계의 산술 검사는 별도다.
- PDF: 쪽수·A4크기, 각 쪽 위의 쪽번호1개, 하단 저작권·학교명 텍스트를 검사한다. 이미지형 PDF에는 적용할 수 없다.
- 전체 쪽 시각 검수: 상단 표가 하나씩 올바른 쪽에 있는지, 본문·표·그림·교표 잘림/겹침, 중앙선·외곽선·꼬리말, 부정어·밑줄·원문자·선지 정렬, 문항 분리·불필요한 공백, 끝/넘김, 정답 표시 잔존을 확인한다. **자동 PASS는 시각 검수를 대신하지 않는다.**

검사기는 이 패키지의 원본 구조용이다. 새 양식이나 한컴이 재작성한 구조를 합격시키려고 기준을 결과로 바꾸지 않는다. 차이를 설명하고 실제 출력을 대조한다. 과거 문제를 검증용이라는 이유로 새 시험 내용으로 쓰지 않는다.
