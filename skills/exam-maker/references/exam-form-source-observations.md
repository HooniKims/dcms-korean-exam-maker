## 본문 적용

- 첫 쪽은 정보 표 아래에서 본문 시작, 이어지는 쪽은 얕은 표 아래2단이 계속된다. 본문 전체를2열 고정높이 표로 재구성하지 않는다.
- 공통 지시문과 지문 묶음, 보기/조건 상자, 인용 밑줄·원문자, 한 줄·3+2·세로5행 선지와 소문항별 배점이 확인된다. 구체 표기는 최신 학교 지침·사용자 결정을 우선한다.
- 시의 행·연, 대화 화자, 산문 단락 표지를 보존한다. 산문 단락 간 빈 줄 제거를 시의 연까지 없애는 규칙으로 확대하지 않는다.
- 서술형은 지문 가까이에 섞거나 뒤에 모일 수 있다. 원본의 ‘선택형 끝→서술형’을 고정 구성으로 강제하지 않는다.
- 끝의 배점표는 현재 문항에서 재계산한다. 정답 하이라이트·검토 색·오탈자·옛 연도는 복제하지 않는다. 과거5~8쪽 분량은 관찰값이며 발문11pt·긴 지문10pt를 줄여4쪽에 맞추지 않는다.

## 원안지 자체의 주의점

1. 한컴에서는 상단 표가1~4쪽에 하나씩, 저작권·교표가 매 쪽에 출력된다. 이전 rhwp의 상단 표 중첩·꼬리말 누락을 원본 파손으로 단정하지 않는다.
2. 서술형 예시 발문은3쪽 오른쪽 단 끝, 보기는4쪽 왼쪽 단 시작으로 갈라진다. 새 문항에서는 발문과 작은 보기를 함께 배치한다. 원본 배치 그대로가 최선은 아니다.
3. 서술형 보기 cellMargin=좌20566/우24929/위13909/아래19304이나 **tc hasMargin=0**이다. 한컴에서 정상 출력된 비활성값을 새 셀의 활성 여백(hasMargin=1)으로 복제하지 않는다. 수치만 보고 원본 전체를 임의 수정하지 않는다.
4. 명시적 pageBreak/columnBreak 없이 빈 문단과 배치에 의존한다. 본문 일괄 교체·빈 문단 일괄 삭제는 표 앵커를 옮길 수 있다.
5. 한컴 HWPX 재저장은 paraPr39개와 image1.jpg 바이트를 바꿔 보존 검사에 실패했다. 인쇄 확인용 사본과 보존 편집 결과를 구별하고 원본을 재저장하지 않는다.
6. 한양신명조는 설치 확인. fontface 목록의 한양견고딕은 미설치로 보고됐지만 원본의 실제 비공백 텍스트 run에는 사용되지 않았다. 실제 텍스트는 한양신명조11/12/15pt와 돋움9/11pt였다. 새 내용에서 미설치 글꼴을 사용하는지 다시 확인한다.
7. HWPX 구조 검사는 통과했다. 별도 verify_hwpx는 원본에서 이어진 paraPr16의 문단 간격 차이와 case/default 차이를 경고했다. 원본 고유 경고와 신규 훼손을 구분하고 원본 스타일을 일괄 수정하지 않는다.

## 범위와 한계

원본4쪽, 학교 기출15쪽(답안지 포함), 본인 대표5회33쪽을 시각 확인했다. 관련 한글 파일17개(양식 포함)를 한컴에서 열었으며, 중복/수정본과 정답·채점기준은 텍스트·구조를 추가 비교했다. 출제 내용의 정답·교육과정 적합성 전수검수와 구별한다. 매번 새 시험지의 내용과 분량이 바뀌므로 최종 결과는 다시 한컴 전체 쪽으로 확인한다.

## 상단 정보 수정 실증

후속 검증의 별도 테스트 사본에서 시행일·요일·교시·학년도·학기·학년·과목·선택형 문항 수를 갱신하고, 같은 셀에 서술형 문항 수 둘째 줄을 추가했다. 이어지는3쪽의 정보도 동기화하고 본문 발문1개를 바꿨다. 한컴에서 다시 열어 출력한4쪽 전체를 시각 확인했으며 상단 글자 잘림이나 표 높이 증가가 없었다. 원본 PDF와 비교한 각 쪽의 표/외곽/중앙선 좌표, 교표 이미지·좌표, 꼬리말 글자·좌표가 모두 동일했다. 구조 보존 검사와 확정정보·PDF 쪽번호 검사가 통과했다.

이는 정보 변경이 레이아웃을 훼손하지 않는지에 대한 시험이다. 가상 시험정보를 실제 출제 조건으로 사용하지 않는다. 원본의 서술형 예시 분리·예시 배점은 이 사본에 그대로 남겼으며, 내용 완성본이나 새 시험지로 배포하지 않는다.
