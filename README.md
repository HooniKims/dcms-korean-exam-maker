# 국어 시험 출제·원안지 편집 스킬

수업 자료와 기출문제를 살펴보고, **출제 계획 → 후보 문항 → 교사 검토 → 한글 원안지 편집 → 출력 검증**까지 이어 주는 AI 에이전트용 스킬입니다. 중학교 국어를 중심으로 만들었으며, 다른 과목에 사용할 때 참고할 일반 출제 절차도 포함합니다.

이 저장소는 독립 실행 프로그램이 아닙니다. 파일을 읽고 수정할 수 있는 AI 에이전트가 지침과 도구를 실행합니다. Windows의 Codex와 한글 2024에서 문서 편집·출력을 검증했습니다.

## 1. 가장 쉬운 설치 방법

**아래 내용을 AI 에이전트에게 그대로 보내세요.**

```text
https://github.com/HooniKims/dcms-korean-exam-maker

이 저장소의 exam-maker 스킬을 설치해 줘.
README.md와 INSTALL.md를 읽고 skills/exam-maker 폴더 전체를 설치해 줘.
HWPX 에디터 스킬과 필요한 Git, Node.js, Python도 확인하고,
없는 것은 무엇을 설치하는지 안내한 뒤 자동으로 설치해 줘.
기존 설치와 사용자 수정본은 보존해 줘.
설치된 한글 프로그램을 찾고, 설치 결과와 사용 방법을 알려 줘.
```

Codex에서는 내장 `skill-installer`로 설치할 수 있습니다. **설치 대상은 저장소 전체가 아니라 `skills/exam-maker`**이며, 그 안의 `references`, `scripts`, `assets`도 모두 필요합니다. `SKILL.md`만 복사하면 양식과 검증 도구를 사용할 수 없습니다.

설치 후 다음 메시지에서 `$exam-maker`를 호출하세요. 목록에서 보이지 않으면 새 대화를 시작하거나 앱을 다시 열고 확인하세요. AI 에이전트에게 “exam-maker가 설치된 경로와 버전을 확인해 줘”라고 해도 됩니다.

> 링크를 읽기만 하는 일반 채팅에서는 PC 설치와 한글 조작을 할 수 없습니다. 로컬 파일·명령 실행 권한이 있는 에이전트가 필요하며, 한글 화면 조작에는 Computer Use가 필요합니다. 다른 에이전트는 각 제품의 스킬 설치 방식에 맞춰야 하고, 동일한 한글 자동 편집 동작은 검증하지 않았습니다.

자세한 설치 절차는 [INSTALL.md](INSTALL.md), Codex의 스킬 개념은 [OpenAI 공식 안내](https://learn.chatgpt.com/docs/build-skills)를 참고하세요.

## 2. 설치 과정에서 준비하는 것

| 구성요소 | 용도 | 처리 방식 |
|---|---|---|
| `exam-maker` | 출제와 편집 절차, 원안지 양식, 검사 도구 | 이 저장소에서 설치 |
| HWPX 에디터 스킬 | HWPX 읽기·편집·검사 지원 | 없으면 지정 버전 설치 |
| Git | 에디터 소스 준비 | 기존 설치 사용, Windows에서 없으면 설치 |
| Node.js·npm | HWPX 에디터 준비와 실행 | 기존 설치 사용, 없으면 설치 |
| Python·문서 라이브러리 | 문서 구조·내용·배치 검사 | 기존 런타임 사용, 필요한 항목 준비 |
| 한컴오피스 한글 | 최종 HWPX 편집·저장·PDF 출력 | 설치된 프로그램 자동 검색 |
| Computer Use | Windows 한글 화면 조작 | 에이전트에서 사용 가능해야 함 |

처음에는 에디터와 의존성을 내려받느라 시간이 걸릴 수 있습니다. 다음 실행부터 정상 설치된 항목을 재사용합니다. 기존 HWPX 스킬을 임의로 덮어쓰거나 삭제하지 않습니다.

한글은 별도로 설치된 제품을 사용하며, 이 스킬이 한글을 구매하거나 인증하지는 않습니다. ‘한글 2024’라는 이름만 찾지 않고 실행 파일, 설치 정보, 실행 중인 창을 함께 확인합니다. 한글 2020 등 다른 설치 경로에 대한 탐색 로직은 포함하지만, 실제 편집 검증은 한글 2024에서 했습니다.

운영체제의 관리자 권한·로그인·보안 확인이 나타나면 사용자가 직접 처리해야 할 수 있습니다. 에이전트는 해당 화면을 우회하지 않습니다.

## 3. 출제 전에 준비할 자료

자료를 한 작업 폴더에 모아 두고 그 폴더를 에이전트에게 알려 주세요. 모두 있어야 시작할 수 있는 것은 아닙니다.

| 자료 | 활용 |
|---|---|
| 교과서, 수업 자료, 학습지 | 실제 배운 내용과 출제 범위 확인 |
| 성취기준·성취수준, 교사용 지도서 | 평가 요소와 출제 청사진 작성 |
| 학교 기출문제와 정답·배점표 | 문항 형식, 편집 관례, 중복 확인 |
| 본인이 출제한 문제 | 발문 표현, 서술형 채점 방식, 문서 서식 파악 |
| 출판사 문제·단원 평가 | 이미 나온 문항과의 중복 확인 |
| 학교 원안지 HWPX | 최종 시험지의 표·단·테두리·꼬리말 기준 |
| 학교 출제 지침 | 해당 학교의 편집·제출 기준 적용 |
| 지난 시험의 문항별 정답률 등 | 새 문항의 난이도 보정 |

기출과 출판사 문제는 그대로 가져오는 문제은행으로 사용하지 않습니다. 참고할 문서와 반드시 중복 검사할 문서를 구분하고, 새 문항의 표현·자료·정답 근거·풀이 과정을 대조합니다.

## 4. 처음 출제를 요청하는 방법

아래 예시에서 대괄호 부분을 바꾸어 보내세요.

```text
$exam-maker

[자료 폴더 경로]의 자료를 보고 [학년] 국어 [중간/기말]고사 출제를 도와줘.
출제 범위는 [교과서 단원·작품·수업 자료]야.
시험 시간은 [분], 총점은 [점]이고,
선택형 [문항 수]개와 서술형 [문항 수]개로 구성해 줘.

먼저 자료를 분류하고 출제 청사진을 만든 뒤,
내가 고를 수 있도록 최종 문항 수보다 여유 있게 후보를 만들어 줘.
각 후보에는 정답, 해설, 성취기준, 배점, 예상 난이도와 풀이 시간을 붙여 줘.
기출 및 출판사 문제와의 중복 검사 결과도 알려 줘.
```

이미 정한 조건은 다시 묻지 않고 반영합니다. 자료에서 확인할 수 없는 중요한 조건만 짧게 질문합니다. 자료 속 과거 날짜·학년·배점·정답은 새 시험의 조건으로 자동 확정하지 않습니다.

## 5. 실제 작업은 이렇게 진행됩니다

1. **자료 정리**: 문제지와 정답지를 짝짓고, 교과서·기출·본인 출제·양식의 역할을 구분합니다.
2. **출제 조건 확정**: 범위, 문항 수, 유형, 배점, 시험 시간과 학교 기준을 정리합니다.
3. **청사진 작성**: 성취기준과 평가 요소를 문항에 배분하고 내용이 한쪽에 몰리지 않게 구성합니다.
4. **후보 문항 제작**: 교사가 비교해서 고를 수 있도록 추천 조합과 대체 문항을 만듭니다.
5. **내용 검토**: 정답의 타당성, 오답의 근거, 중복, 풀이 시간, 서술형 조건과 채점 기준을 확인합니다.
6. **문항 선택·수정**: 교사의 결정을 반영하고 번호·배점·난이도 구성을 다시 계산합니다.
7. **원안지 편집**: 작업 사본에 본문을 넣고 시험 정보도 수정합니다. Windows에서는 실제 한글을 열어 저장·출력합니다.
8. **전체 쪽 검증**: HWPX 구조 검사와 PDF 시각 검토를 함께 하고, 문제가 있으면 수정 후 다시 확인합니다.

후보 검토 문서는 기본적으로 DOCX로 정리합니다. 최종 시험지 HWPX, 확인용 PDF, 정답·해설·채점 기준, 문항 대응표와 검증 결과는 요청한 작업 범위에 맞춰 제공합니다. 학생용 문제지와 교사용 정답 자료는 구분합니다.

## 6. 원안지 편집을 요청하는 방법

```text
$exam-maker

확정한 문항을 [원안지양식.hwpx 경로]의 작업 사본에 편집해 줘.
시험 정보는 [학년도·학기·고사명·일시·학년·과목]으로 바꿔 줘.
원안지의 표 크기, 두 단, 테두리, 꼬리말은 유지해 줘.
한글에서 저장하고 다시 열어 본 뒤, 전체 쪽을 PDF로 확인해 줘.
결과는 [산출물 폴더]에 저장해 줘.
```

기존 후보로 양식을 시험하려면 “이 후보를 사용해 전체 분량의 편집 테스트본을 만들어 줘”라고 요청하세요. 테스트본은 실제 시험의 문항 확정과 구분합니다.

포함된 학교 양식 프로필에는 다음 편집 기준이 들어 있습니다.

- 상단의 학년도·학기·시험명·일시·문항 수·쪽번호는 수정하되 표의 크기와 배치를 보존합니다.
- 발문 번호 뒤에는 실제 탭과 내어쓰기를 넣어 둘째 줄도 본문 시작 위치에 맞춥니다.
- 배점이 줄 끝에서 갈라지면 `(5점)` 전체를 다음 줄로 옮기고 배점만 오른쪽 정렬합니다.
- 범위의 물결은 가운데 모양의 `~`를 사용하며, 마지막 쪽 다단 구분선도 다른 쪽과 같은 하단 높이까지 유지합니다.
- 긴 지문은 연결된 문단 테두리로, `<보기>`와 `<조건>`은 원본 개체 서식으로 작성합니다.
- 공통 안내는 `[9~12, 서2] 다음을 읽고 물음에 답하시오.`처럼 범위까지 굵은 한 줄로 씁니다.
- 선택지 ①~⑤는 줄간격 160%를 적용하고 선택지 사이의 추가 문단 간격을 없앱니다.
- 마지막 쪽을 제외한 하단의 큰 빈 공간은 문항 묶음의 배치와 순서를 조정해 줄입니다.
- 이어지는 쪽에는 홀짝에 맞는 계속 표시를 넣고, 마지막에 배점별 문항 수·소계·총점을 표시합니다.
- 상단에 있는 문항 수와 총점 안내를 본문 시작에 중복해서 넣지 않습니다.

새 학교의 양식이 있으면 그 양식과 최신 지침을 우선합니다. 포함된 양식의 학교명·교표·날짜를 다른 학교의 시험에 그대로 사용하지 않습니다.

## 7. 수정은 이렇게 요청하세요

| 상황 | 요청 예시 |
|---|---|
| 문항을 교체하고 싶을 때 | “4번을 같은 성취기준의 다른 문항으로 바꾸고 정답·배점표도 맞춰 줘.” |
| 난이도를 조정할 때 | “핵심 개념은 유지하고 추론 단계와 자료 읽기 부담을 줄여 줘.” |
| 아래쪽에 공간이 많이 남을 때 | “선택지 간격을 늘리지 말고 문항 묶음 배치를 바꿔 하단을 다시 맞춰 줘.” |
| 지문이나 표가 잘렸을 때 | “문제 쪽뿐 아니라 수정으로 영향을 받은 다음 쪽까지 다시 출력해 확인해 줘.” |
| 시험 정보만 바꿀 때 | “표의 크기는 유지하고 상단 시험 정보와 전체 쪽번호만 갱신해 줘.” |

## 8. 검증 범위와 환경 차이

자동 검사는 문서 구조, 내용 보존, 배점 집계, 탭 정렬, 지시문 줄 수, 선택지 간격 등을 확인합니다. 실제 잘림·겹침·읽기 순서는 **출력된 모든 쪽을 눈으로 확인하는 과정**이 추가로 필요합니다.

현재 기록에는 Windows 한글 2024에서 만든 6쪽 테스트본과 122개 회귀 테스트가 포함됩니다. 일반 HWPX 검사기의 문단 간격 관련 경고와 비최종 쪽 내부의 남은 문항 간격은 [검증 기록](skills/exam-maker/references/native-exam-test-results.md)에 구분해 적었습니다. 오류가 없다는 말만으로 모든 렌더러에서 같은 결과라고 판단하지 않습니다.

Mac 또는 한글이 없는 PC에서도 자료 정리와 문항 작성, HWPX 대체 편집은 진행할 수 있습니다. 다만 한글의 실제 조판 검증은 별도로 필요합니다. 앱에서 편집 가능한 HWPX인지와 실제 시험에 쓸 내용인지도 각각 검토합니다.

## 9. 설치·실행이 막힐 때

| 증상 | 확인할 내용 |
|---|---|
| 스킬이 보이지 않음 | `exam-maker/SKILL.md`와 하위 폴더가 함께 설치되었는지 확인 후 새 메시지에서 호출 |
| 이미 설치된 폴더가 있음 | 기존 수정본을 먼저 비교·백업하고 업데이트 요청. 무조건 덮어쓰지 않음 |
| Git·Node.js·Python 준비 실패 | 환경 보고서의 누락 항목, 인터넷 연결, 조직 설치 정책 확인 |
| 한글을 못 찾음 | 설치된 한글의 위치를 알려 주거나 실행한 뒤 다시 탐색 요청 |
| Computer Use가 없음 | 해당 기능이 있는 에이전트 환경 사용. 미검증 부분을 결과에 남김 |
| 파일 접근·보안 확인 창이 뜸 | 화면을 확인한 후 사용자가 직접 처리하고 에이전트에게 완료 사실 전달 |
| 글꼴·줄바꿈이 달라짐 | 실제 설치 글꼴과 한글 버전 확인 후 해당 PC에서 재출력 |

## 10. 저장소 구성과 개발용 검사

```text
skills/exam-maker/
  SKILL.md       # 에이전트가 읽는 시작 지침
  agents/        # 스킬 표시 정보
  references/    # 출제·편집 기준과 검증 기록
  assets/        # 원안지, 기본 DOCX, 재사용 개체
  scripts/       # 환경 준비와 문서 검사 도구
INSTALL.md       # AI 에이전트용 설치 절차
requirements-dev.txt
```

개발자는 저장소 폴더에서 다음과 같이 검사할 수 있습니다.

```sh
python -m pip install -r requirements-dev.txt
python -m unittest discover -s skills/exam-maker/scripts -p "test_*.py"
```

문항을 새로 만들거나 HWPX를 수정한 뒤에는 회귀 테스트만 통과하는 것으로 끝내지 말고, 해당 문서의 검사 명세와 실제 한글 PDF로 검증하세요. 상세 명령은 [원안지 구성·검사 안내](skills/exam-maker/references/native-exam-components.md)와 [Windows 한글 작업 안내](skills/exam-maker/references/windows-hancom-computer-use.md)에 있습니다.

업데이트할 때는 에이전트에게 이 저장소 링크와 함께 “현재 설치본의 사용자 수정 사항을 보존하면서 최신 버전으로 업데이트해 줘”라고 요청하세요.
